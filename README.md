# Fantasy Squad

Character designs for the Fantasy Squad game.

Cute, colorful, detailed cartoon illustrations inspired by original child sketches.

## Characters

- Robot
- Giant
- Knight
- Wizard
- Multi-legged Creature
- Carrot Monster
- Caveman
- Archer
- Alien
- Brawler
- Riot Police
- Security Guard
- Spiky Ball Monster
- Worm / Caterpillar
- Chinese Flying Man
- Little Soldier
- Villager
- Unknown
- Path Figure

## Images

The full set of generated character images is available as a downloadable package from the conversation. You can extract and commit them into the `characters/` directory.
