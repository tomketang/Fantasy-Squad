# Fantasy Squad 奇幻小队

收集可爱的奇幻角色，用星积分养成，组队闯关。自动战斗，关键技能由你来放。

## 本地运行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

开发服务器默认在 [http://127.0.0.1:8080](http://127.0.0.1:8080)。

```bash
npm run build
npm test
```

## 玩法

- 登录后进入营地，用星积分培养角色
- 最多编入 3 名角色组队
- 自动战斗，主动技能需要你来放
- 通关解锁新角色，并收录进图鉴

角色原画在 `public/characters/`。

## 技术栈

React 19、TanStack Start、Vite、Tailwind CSS、Zustand。
